# 微信扫码点餐 / 点单小程序（SAAS 版）源码

SaaS 版扫码点餐小程序源码，支持商家入驻模式，一套系统可开通无数餐饮门店账号，包含顾客小程序端、商家后台、PC 收银台，适合创业者搭建餐饮服务平台，私有化部署，支持二次开发。

顾客微信扫码即可堂食点餐、外卖下单、到店自提，支持菜品规格选择、购物车、在线支付，订单实时推送后厨打印小票。自带会员储值、积分、优惠券、满减等营销工具。SaaS 总后台用于管理入驻商家、设置平台抽佣、套餐定价，独立给每个商家分配子后台，商家自主维护菜品、桌台、查看营业报表。
